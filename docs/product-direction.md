# Product direction

Speak through a case. See a clinically specific, compact working sheet change coherently. Read it without chasing moving text. Choose the models and microphone, then share a clean runnable application.

## This release

- Clinical substance: named actions, explicit dose/route when appropriate, specific decision-changing history and physical findings. Short wording retains important qualifiers. Unknown patient dependencies remain visible beside the affected action.
- Reading: stable item identities and positions; unchanged language stays verbatim. Priority changes alter emphasis. Actual corrections appear immediately. No similarity gate, hidden reversal or permanent completion ratchet.
- Signposting: ink for content; purple identifies medicines, blue investigations, red immediate concern. Emphasis belongs to the clinical head term and dose. Qualifiers remain readable plain text.
- Voice: device choice and acoustic/direct speech modes; configurable phrase pause; visible input level, queue state and transcription errors. Pause finishes captured speech. A retry retains failed speech in memory.
- Models: three independent clinical roles, independently selectable provider/model. Available model lists come from the user's provider account. Key entry is temporary by default, with explicit opt-in browser persistence and a Forget action. Keys never enter a source bundle.
- Distribution: local Node application, source ZIP and container recipe. Hosting requires explicit origin and access protection. Hosted sharing is not a public anonymous endpoint spending someone else's API key.

## Further work that would materially expand the tool

- A trusted local protocol library: versioned documents, exact supporting passages, explicit conflict with model advice, and the date each recommendation was checked.
- Image interpretation as an explicit question with the actual image and its provenance, not an inferred result from speech.
- Clinical simulation and replay evaluation: diagnosis transitions, revised doses, cancellation, negation, overlapping speakers, noise and provider outages.
- Team roles and handover: controlled encounter sharing with access boundaries and a visible distinction between proposed, ordered, administered and reassessed.

These are separate capabilities. None is implied by a working transcription pipeline or an attractive sample. Clinical validation remains necessary for clinical use.
