← Clinical Live

Listen. Keep the clinical picture in view.

Clinical Live turns spoken case discussion into a compact working differential, history, physical assessment, investigations, management and one direct answer. The conversation is the input. The sheet updates as each model finishes.

Download and run

Download the clean source archive. Extract it, install Node.js 22.9 or newer, then open a terminal in the extracted folder:

npm ci
npm start

Open http://127.0.0.1:8840. The sample runs immediately. Open Voice & models, connect a Gemini or OpenAI key, use the preconfigured models or change any role, and press Start listening. Keys are temporary by default. Select Remember key on this device to save the key unencrypted in this browser and reconnect automatically on return. Model choices are remembered too. Forget / disconnect removes the selected saved key. An optional private .env file can supply server defaults.

Make it yours

VoiceChoose a microphone, room or direct input, and the pause that ends a phrase. The microphone test is local and sends no test audio.
ModelsChoose speech transcription, clinical assessment, management and direct answers independently. Load available model IDs from your provider account. Gemini 3 thinking can be adjusted separately.
Clinical focusEmergency department, resuscitation or acute medicine adjusts the model instructions. It does not impose a timer or rearrange the sheet.
DisplayAdjust text, line height, row spacing, column spacing, category labels, dividers, differential cues and colour. Compact, Dense and Larger are starting points.
CorrectionsSay the correction. Existing items retain their places while revised values replace them. The transcript also accepts text for testing and correction.

What the marks mean

Unmarked items are generated suggestions. ● marks a spoken finding, ↗ requested an explicit request, and ✓ done/result a reported action or result. The model assigns these states; check them against the transcript. Hover an item to see its supporting utterance numbers. References to speech are not verified medical citations.

Host a private workspace

The source includes a Dockerfile, compose.yaml and docs/hosting.md. Use a host that can run a Node server or container behind HTTPS. Set PUBLIC_ORIGIN to its exact public URL and ACCESS_PASSWORD to an access code of at least 16 characters. The app then requires that code, keeps browser configurations in separate sessions, and rejects other origins.

GitHub can distribute the source. GitHub Pages alone cannot run the provider server or keep API keys private. The default local server binds only to your own computer. The container recipe and hosting instructions prepare deployment; they do not publish a site.

Present limits

Cloud providers receive the submitted audio and clinical context. The app does not save encounters to a database, but provider retention policies still apply. It does not remove identifiers automatically. Live output is generated from the transcript and model knowledge: no current-guideline lookup, image interpretation, chart integration, test ordering or treatment execution is connected. It has not been clinically validated.

Audio is processed in short phrases, not a continuous realtime model stream. Actual speech and update timings appear on the sheet. Provider failures leave the previous display visible and offer Retry; New cancels the encounter and its pending work.
